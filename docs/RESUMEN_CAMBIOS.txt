CÓMO FUNCIONA AHORA:

  1. Cada programa COBOL contiene:
     COPY PATHS-FILE FROM "..\copies"
     
  2. PATHS-FILE (PATHS.CPY) tiene:
     PATH-CONFIG = ".\config"
     PATH-DBIO = ".\src\dbio"
     FIL-DB-CONFIG = "db_config.cfg"
     (etc...)
     
  3. Programas construyen rutas dinámicamente:
     MOVE FUNCTION CONCATENATE(
         PATH-CONFIG "\" FIL-DB-CONFIG
     ) TO WS-RUTA.
     
  4. Resultado: WS-RUTA = ".\config\db_config.cfg"
