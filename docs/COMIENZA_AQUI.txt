💡 CONCEPTO CLAVE: Cómo Tu Código Sabe Dónde Buscar Archivos

ANTES (❌ Hardcodeado):
    ASSIGN TO "db_config.cfg"
    ✗ Si mueves el archivo, se rompe

DESPUÉS (✅ Dinámico):
    COPY PATHS-FILE.
    MOVE FUNCTION CONCATENATE(
        PATH-CONFIG "\" FIL-DB-CONFIG
    ) TO WS-RUTA.
    ASSIGN TO WS-RUTA.
    ✓ Si cambias rutas, solo editas PATHS.CPY
    ✓ Todo el código automáticamente usa nuevas rutas
